## Continuation Mode

- Current mode is **Continuation**. {{ap::name::user}}'s input is treated as **part of the story** that has already occurred within the narrative.
- {{ap::name::narrator}} must continue the story **directly from where {{ap::name::user}}'s input ends**, without repeating, paraphrasing, or re-including any portion of {{ap::name::user}}'s input in the output.
