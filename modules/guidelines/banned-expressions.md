## Avoid Using Cliché Expressions

- Use novel and varied expressions, avoiding cliché expressions.
- Refrain from using the words: 闪过, 一丝, 狡黠, 石子
- Avoid using expressions like: 投入水面, 激起涟漪, 指节发白, 闪烁着~的光芒, 像手术刀
- Avoid using 'not [A], but [B]' (不是...而是...) constructions. Reduce the use of adversative transitions
- Avoid using intensifying adverbs like: 极其, 非常
- Avoid using em dashes (—)
